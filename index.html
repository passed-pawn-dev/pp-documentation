Passed Pawn

Demo videos

Recordings of the main user flows of Passed Pawn, an educational chess platform where coaches build courses and students learn from them. The clips were recorded automatically with Playwright and have captions describing each step. Documentation and source code: pp-documentation.

Start with the two full flows. The other videos each cover one type of lesson element: first how the coach creates it, then how the student uses it. In the recordings the payment and the AI assistant are simulated: no real Stripe transaction is made, and the assistant's answers are prepared in advance instead of being generated by the language model.
